# 诗词 · 参赛版（Vue3 + Vite，电脑端优先）

## 启动
1. 安装 Node.js（建议 18+）
2. 进入项目目录：
   - `npm i`
   - `npm run dev`

浏览器打开：Vite 控制台提示的地址（默认 http://localhost:5173）

## 说明
- 默认电脑端（桌面端）使用左侧栏导航；屏幕变窄会自动切换为底部导航。
- 首次进入会要求选择身份（小学/初中/高中/爱好者），身份会影响首页与学习路径的内容。
- 朗诵页包含录音与简易波形展示（演示版规则评分，后续可接 AI）。

## 后续可扩展（比赛加分）
- 诗词详情页：原文/注释/译文/赏析/考点（按身份改变深度）
- AI 教师：接入真实大模型接口（讲解/答疑/朗诵纠错）
- 作品社区：朗诵作品卡、排行榜、评论
- 可视化：学习时长、掌握度、意象标签云
