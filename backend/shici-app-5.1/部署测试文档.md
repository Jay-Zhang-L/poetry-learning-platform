# 部署测试文档

本次部署测试针对古诗词学习平台在本地服务器环境（Windows + JDK 17 + MySQL 8.0）的部署过程进行验证。测试内容包括：后端 Spring Boot 服务的打包构建（Maven compile）、数据库脚本导入（shici.sql）、应用启动与端口监听（8080）、前端 Vue 项目构建与联调（Vite dev server 5173）、静态资源路径映射（诗词封面、知识库图片、音视频文件）、文件上传目录权限、第三方 API 连通性（DeepSeek AI、智谱 AI、百度语音）。经测试，系统可正常完成构建部署并稳定运行，前后端接口通信正常，各项服务功能可用，部署流程满足上线要求。
