# 智能小助手功能说明

## 功能概述

在页面右下角添加一个悬浮的智能助手组件，用户可以点击展开聊天窗口，与中国传统文化相关的AI助手进行对话。

## 技术方案

| 项目 | 说明 |
|------|------|
| AI服务商 | 智谱AI (https://open.bigmodel.cn/) |
| 模型 | glm-4-flash (免费) |
| 接口协议 | OpenAI 兼容格式 |
| HTTP客户端 | OkHttp 4.12.0 |

## 后端修改清单

### 1. 依赖添加 (pom.xml)

```xml
<!-- HTTP Client for AI API -->
<dependency>
  <groupId>com.squareup.okhttp3</groupId>
  <artifactId>okhttp</artifactId>
  <version>4.12.0</version>
</dependency>
```

### 2. 新增文件

| 文件路径 | 说明 |
|----------|------|
| `service/ChatAssistantService.java` | 核心服务类，调用智谱AI API |
| `controller/ChatAssistantController.java` | REST接口控制器 |
| `domain/dto/AssistantChatRequest.java` | 请求DTO |
| `domain/dto/AssistantChatResponse.java` | 响应DTO |

### 3. 配置文件 (application.yml)

```yaml
# AI 小助手配置 (智谱AI)
ai:
  zhipu:
    api-key: 你的API密钥
    model: glm-4-flash
    base-url: https://open.bigmodel.cn/api/paas/v4
```

## API 接口

### 发送消息

**请求**
```
POST /api/assistant/chat
Content-Type: application/json

{
  "message": "用户问题",
  "history": [
    { "role": "user", "content": "历史消息1" },
    { "role": "assistant", "content": "历史回复1" }
  ]
}
```

**响应**
```json
{
  "code": 200,
  "data": {
    "reply": "AI回复内容",
    "success": true
  }
}
```

### 健康检查

```
GET /api/assistant/ping
```

## 前端集成

### 组件文件

创建 `src/components/ChatAssistant.vue`，包含：
- 悬浮触发按钮
- 聊天面板（头部、消息区、输入区）
- 消息发送逻辑
- 样式与动画

### 使用方式

在 `App.vue` 或布局组件中引入：

```vue
<template>
  <router-view />
  <ChatAssistant />
</template>

<script setup>
import ChatAssistant from '@/components/ChatAssistant.vue'
</script>
```

## 小助手角色设定

系统提示词定义了小助手的角色：

- 名称：诗词小精灵
- 职责：回答古诗词、传统文化相关问题
- 风格：简洁友好，每次回复不超过200字
- 特点：适当使用表情符号增加亲和力

## 注意事项

1. **API Key 安全**：生产环境建议使用环境变量管理密钥，不要提交到代码仓库
2. **费用**：glm-4-flash 模型免费，其他模型按量计费
3. **并发**：OkHttp 已配置连接池，支持并发请求
4. **超时**：连接超时30秒，读取超时60秒
