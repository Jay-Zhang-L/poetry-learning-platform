# 扩展性测试文档

古诗词学习平台采用前后端分离架构（Vue + Spring Boot），具备良好的扩展性。后端基于 Spring Boot 分层设计（Controller → Service → Mapper），新增功能模块只需添加对应的三层代码即可接入，无需修改已有业务逻辑；MyBatis Mapper XML 与 Java 接口分离，数据库查询可灵活扩展；CORS 配置支持动态添加前端来源域名，便于多端接入；AI 模块通过配置文件管理 DeepSeek、智谱、百度语音等多个第三方 API，切换或新增 AI 服务商只需修改配置和对应 Service 实现；文件上传模块支持按类型（图片、音频、视频）独立扩展存储策略和格式白名单；静态资源路径通过 WebMvcConfig 统一映射，新增资源目录只需添加一行配置。整体系统在功能模块、AI 能力、存储方案、前端接入等方面均可独立扩展，不影响现有业务运行。
